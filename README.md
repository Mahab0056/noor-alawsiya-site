# موقع ومنصة مدرسة نور الأوصياء للدراسات القرآنية

الموقع الحي: https://noor-alawsiya.com (Railway، مشروع `noor-alawsiya-com`، يُنشر من فرع `main`).

## التشغيل محلياً

```bash
npm install
npm run dev
```

```bash
npm run lint
npm run build
```

## البنية

- `app/` الصفحات: الرئيسية `/`، سجل الدورات والأساتذة `/courses`، سياسة الخصوصية `/privacy`.
- `components/` الترويسة والتذييل، بطاقة الدورة، شبكة الأساتذة، الأيقونات.
- `lib/data.ts` سجل الدورات والأساتذة (من سجل المدرسة بتاريخ 18/11/2026). القيمة `null` تعني أن المعلومة ناقصة في السجل وتُعرض «غير مذكور».
- `app/globals.css` نظام التصميم (أصفر `#FFFA00` وأسود)، و`app/site.css` إضافات الموقع.
- `db/schema.sql` مسودة مخطط قاعدة البيانات للمراحل القادمة. لم تُنشأ أي قاعدة بيانات بعد.

## قواعد المحتوى

- لا تُنشر أسماء الطلاب أو المتخرجين إلا بموافقة المدرسة (وولي الأمر لمن هو دون 18).
- لا تُخترع معلومة ناقصة في سجل المدرسة.

## المراحل

1. الأساس والموقع العام الجديد (هذه المرحلة).
2. التسجيل من الموقع مع الاستبيان ولوحة الطلبات.
3. الدورات والدروس وبوابة الطالب.
4. الامتحانات والنتائج والتصدير.
